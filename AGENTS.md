# HS-Math Project Instructions

## Purpose
Project-specific engineering hygiene and delivery rules for HS-Math.

## Required Workflow For Every New Ask
1. Add/update request entry in inputs/REQUEST_LOG.md.
2. Reflect product requirement updates in inputs/PRD.md.
3. Update guiding principles when needed in inputs/PRINCIPLES.md.
4. Implement code/data updates.
5. Update architecture/design docs:
   - inputs/HLD.md
   - inputs/LLD.md
6. Record change summary in inputs/CHANGELOG.md.
7. Keep README user docs in sync (especially keybindings and controls).
8. Validate changed files for errors before commit.
9. Commit and tag release baseline as requested.

## Release Hygiene
- Use semantic tags (vX.Y.Z) for baselines.
- Push branch and tags together.
- Keep changelog entries concise and user-facing.

## Shared Cross-Project Hygiene
- Reuse inputs/HYGIENE_CHECKLIST_TEMPLATE.md as the starter checklist in new projects.
